# 角色变声器

在自己电脑上运行的实时变声器（Windows）。对着麦克风说话，变声后的声音发到 Discord、QQ、YY 或游戏语音里，也可以转换录好的音频文件。所有处理都在本机显卡上完成，不上传任何声音。

**这个仓库不带任何声线。** 声线包（RVC v2 的 `.pth` 模型和 `.index` 索引）需要你自己准备，在界面里一键导入。请只导入你有权使用的声线，不要用它冒充他人。

## 功能

- 一个大开关开始 / 停止变声，延迟约 0.7 秒（本机 VB-CABLE 实测，不含语音软件本身的延迟）
- 两个输出开关：**发到语音软件**（虚拟麦克风）和 **耳返**（自己在耳机里听），可以一起开
- 全局快捷键（默认 `Ctrl+Alt+V`）和托盘图标，打游戏时不用切窗口
- 记住上次的声线、音色强度、风格、音高和设备
- 降噪（GTCRN）和语音检测（Silero VAD），不说话时保持安静
- 两种风格：**音色优先**更像目标声线，**通话清晰**咬字更清楚
- 音高三档：自动 +2（默认）、自动 +4、模型默认
- 文件变声：录音或导入 WAV / FLAC / MP3 / OGG，原声和结果对比试听，保存为 WAV
- 第一次打开有新手引导：选麦克风试音、设置 Discord、记住快捷键

## 下载（推荐）

到 [Releases](../../releases/latest) 下载 `VoiceChanger-1.0.0-win64.zip`，解压到路径里没有中文和空格的地方（例如 `D:\VoiceChanger`），双击 `start-gui.cmd`。便携版自带 Python 和所有依赖，**不用另外安装 Python**。第一次启动会下载共用的推理模型（需要联网），之后可以离线使用。

需要：Windows 10 或 11 64 位，支持 DirectX 12 的显卡。想发到语音软件还要装 [VB-CABLE](https://vb-audio.com/Cable/)，见下文。

## 从源代码运行

### 需要什么

- Windows 10 或 11
- [Python 3.13](https://www.python.org/downloads/)（安装时勾选 “Add python.exe to PATH”，并保留 `py` 启动器）
- 支持 DirectX 12 的显卡（NVIDIA、AMD、Intel 都可以；作者用 RTX 5060 Ti 测试）
- 想把变声发到语音软件，还需要一个虚拟麦克风，推荐 [VB-CABLE](https://vb-audio.com/Cable/)（免费，自己去官网下载安装，装完重启电脑）

### 安装和第一次运行

1. 下载本仓库（绿色 “Code” 按钮 → “Download ZIP” 并解压，或者 `git clone`）。路径里最好不要有中文和空格，例如放在 `D:\VoiceChanger`。
2. 双击 `start-gui.cmd`。第一次会建立运行环境、安装依赖，并下载共用的推理模型（ContentVec、RMVPE、GTCRN、Silero VAD，都会校验 SHA-256），需要联网，几分钟到十几分钟不等。
3. 右上角出现 **“引擎就绪”** 后就能用了。之后可以离线运行。

想放到任务栏：运行一次 `powershell -NoProfile -ExecutionPolicy Bypass -File make-shortcut.ps1`，右键生成的“角色变声器”快捷方式，选“固定到任务栏”。

## 导入声线

1. 点左栏下方的 **“＋ 导入声线”**。
2. 起个名字，选模型 `.pth`；同一个文件夹里有 `.index` 时会自动填上，没有就手动选。
3. 选音域：女声选“女声（推荐）”，更高的少女音选“高音少女”，低沉女声或少年选第三项，男声选“男声”。之后在主界面的“音高”里还能再调。
4. 点 **“开始导入”**。导入器会检查是不是 RVC v2 模型、索引是否配套，导出推理图并试跑一秒，通过后自动重启引擎并选中新声线。

第一次导入要额外下载约 2 GB 的导出工具（PyTorch），之后每次一两分钟。只支持 **RVC v2、带音高（f0）** 的模型；`.index` 必须和模型是同一次训练出来的。

命令行也可以导入，参数更多（固定移调、检索比例等）。便携版把下面的 `.venv\Scripts\python.exe` 换成 `runtime\python.exe`：

```powershell
.venv\Scripts\python.exe tools\import_rvc.py --voice mine --name "我的声线" --checkpoint "D:\模型\mine.pth" --index "D:\模型\mine.index" --target-hz 300
```

导入的声线存在 `models/local-rvc/`。换电脑时把这个文件夹整个复制过去就行。

## 在 Discord 里用

1. 装好 VB-CABLE 并重启电脑。
2. 在变声器底部的“麦克风”里选你真正的麦克风，打开 **“发到语音软件”**（想自己也听到就再打开“耳返”），点中间的大圆键。
3. 在 Discord 的“用户设置 → 语音与视频 → 输入设备”里选 `CABLE Output (VB-Audio Virtual Cable)`，输出设备继续用耳机。
4. Discord 的输入配置（Input Profile）选 **Studio**，或者关掉噪声抑制，避免它把变声结果再处理一遍。

朋友先听到原声、过一会儿又听到变声时：检查 Discord 是不是还选着真麦克风，以及 Windows 麦克风属性里的“侦听此设备”有没有打开。

没有 VB-CABLE 时，Steam 的 Steam Streaming Microphone 也能当虚拟麦克风用。

## 常用设置

- **快捷键、托盘**：右上角“设置 → 常用”。可以换成 `Ctrl+Shift+V`、`Ctrl+Alt+M`、`F8`–`F10` 或关掉。
- **长时间通话**：默认每约 6 分钟自动重开一次实时会话，避免长时间运行后声音变差；会有很短的停顿。在“设置 → 高级”里可以改成 5,000 包或关闭。
- **低延迟实验档**：“设置 → 高级”里的 100 ms 档，延迟更低但可能偶尔断续。
- **重新运行新手引导、打开设置 / 日志文件夹**：“设置 → 高级”。

命令行参数（在项目文件夹里的 PowerShell 运行）：

```powershell
.\start-gui.cmd --fresh                      # 这次不读也不保存设置
.\start-gui.cmd --live-restart-packets 0     # 关闭自动重开
.\start-gui.cmd --pitch-preset model         # 用模型默认音高启动
```

## 常见问题

- **一直显示“引擎未连接”**：点右上角“重新连接”。还不行就看 `.run\` 里的日志，最常见的是第一次下载模型时断网。
- **没有声音 / 声音很小**：界面会提示“没有检测到说话声”。检查选的麦克风对不对，Windows 里麦克风音量是否太低。
- **爆音**：界面会提示，把麦克风音量调低一点。
- **导入失败**：看导入窗口里的输出。常见原因是模型不是 RVC v2、没有音高（f0），或者索引和模型不配套。

## 隐私

声音只在本机处理。程序只在第一次准备环境和导入声线时联网，下载依赖和模型；不收集、不上传任何数据。设置保存在 `%APPDATA%\CharacterVoiceChanger\`。
